# Portafolio — Agustín Miranda

Sitio personal en React + TypeScript + Vite, listo para publicar en Vercel.

## Desarrollo local

```bash
npm install
npm run dev
```

## Publicar en Vercel

1. Crea un repositorio de GitHub y sube todos los archivos de esta carpeta.
2. En https://vercel.com/new, importa ese repositorio.
3. Vercel detectará Vite. Build command: `npm run build`; output directory: `dist`.
4. Pulsa Deploy. Los siguientes pushes a GitHub actualizarán el sitio.

## Personalización

- Edita textos y secciones en `src/main.tsx`.
- Cambia colores y estilos en `src/style.css`.
- Sustituye `public/CV_Agustin_Miranda.pdf` por una versión actualizada de tu CV.
- Añade un enlace a tu GitHub cuando quieras hacerlo público.
